# Спектр — сайт окон

Один статический сайт, без сборки и внешних JavaScript-зависимостей.

## Структура

```text
index.html                 Главная страница
contacts/
  index.html               Страница контактов
  assets/                  Карты офисов и иконка страницы
assets/
  css/
    main.css               Базовые стили главной
    design.css             Оформление главной
    night.css              Общая тёмная палитра
    window-story.css       Блок разборки окна
    reviews.css            Кнопка звонка и отзывы
    contacts.css           Стили страницы контактов
  js/
    main.js                Каталог и калькулятор
    motion.js              Анимации интерфейса
    window-story.js        Анимация устройства окна
    reviews.js             Переключение отзывов
    contacts.js            Поиск офисов и часы работы
  *.png, *.webp            Изображения, логотип и иконка
docs/
  review-sources.md        Источники и дата проверки отзывов
```

Раздавайте корневую папку любым статическим HTTP-сервером.
Главная доступна по `/`, контакты — по `/contacts/`.
Порядок CSS-подключений в HTML важен: оформление накладывается на базовые стили.
Пути к изображениям внутри CSS считаются от папки `assets/css`,
а пути изображений каталога в JavaScript — от главной HTML-страницы.

Страница избранных отзывов доступна по /reviews/. Стили: assets/css/reviews-page.css. Страница имеет собственные CSS и JS без зависимостей от главной: assets/css/reviews-page.css и assets/js/reviews-page.js. JS добавляет поиск, тематические фильтры и показ по 6 карточек; без JS доступны все 10 отзывов.
