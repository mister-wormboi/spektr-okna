# Спектр — сайт окон

Статический сайт без сборки и внешних JavaScript-зависимостей. Для просмотра
раздавайте корневую папку обычным HTTP-сервером, например `python3 -m http.server 8000`.

## Страницы

| Адрес | Назначение |
| --- | --- |
| `/` | Главная: калькулятор, миникаталог, четыре примера, отзывы, FAQ, филиалы |
| `/catalog/` | Полный каталог с фильтрами и сортировкой |
| `/solutions/` | Четыре демонстрационных решения |
| `/calculator/` | Полный калькулятор |
| `/about/` | О компании |
| `/contacts/` | Филиалы и часы работы |
| `/reviews/` | Отзывы с фильтрами и дополнительной загрузкой |

## Где менять код

- `assets/js/catalog-data.js` — единый список товаров, цены и изображения.
- `assets/js/catalog-render.js` — общие фильтрация, сортировка и карточка каталога.
- `assets/js/main.js` — миникаталог и появление элементов главной.
- `assets/js/card-strips.js` — общие стрелки и счётчик мобильных лент примеров и филиалов;
  свайп работает через обычную прокрутку и CSS scroll-snap, без библиотеки.
- `assets/js/catalog-page.js` — управление полным каталогом.
- `assets/js/calculator.js` — общая формула и интерфейс обоих калькуляторов.
  При переходе на полную страницу параметры передаются через URL.
- `assets/js/window-story.js` и `assets/css/window-story.css` — однократная разборка окна.
- `assets/js/motion.js` — hero, индикатор прокрутки и небольшие эффекты интерфейса.
- `assets/js/contacts.js` — фильтры филиалов и часы работы по московскому времени.
- `assets/css/header-refresh.css` и `assets/css/footer.css` — общие шапка и подвал.
  Их стили не дублируются в других файлах.
- `assets/css/typography.css` — два шрифта, три размера, отступы подписей и прямые углы.
  Подключается последним. Правила: [типографика](docs/typography.md).
- `assets/css/home-refresh.css` — расположение блоков главной;
  остальные файлы названы по странице или компоненту.

`main.css`, `design.css` и `night.css` пока образуют существующие слои базовых
стилей, оформления и палитры. Порядок подключений имеет значение. При дальнейших
изменениях редактируйте правило компонента в его файле, а не добавляйте очередное
переопределение в конец общего CSS.

Общие шапка и подвал находятся в HTML семи страниц. При изменении ссылок обновляйте
все страницы: автоматической шаблонизации в проекте нет.

## Изображения

Изображения каталога и первого экрана — WebP; карты филиалов — `contacts/assets/*.webp`.
Варианты `*-small.webp` подключены через `srcset` и `sizes`; мобильный фон —
`hero-mobile.webp`. При замене изображения каталога обновляйте оба размера.
Примеры сохраняют кадрирование 9:16 на всех экранах.
PNG используется для небольшой иконки сайта. Пути в CSS считаются от `assets/css`.
Полный каталог передаёт `../` общему построителю карточек.
Изображения решений иллюстративные, это не фотографии выполненных заказов.
Источники: [изображения](docs/catalog-image-prompts.md), [отзывы](docs/review-sources.md).

## Проверки

Нужен Node.js с встроенным тестовым раннером; устанавливать пакеты не требуется:

```sh
node --test tests/*.test.js
```

Проверяются формулы калькулятора, каталог, запасное поведение без анимаций,
освобождение наблюдателей, однократный запуск схемы окна, обработка прокрутки,
локальные ссылки, изображения и общие стили. Эти проверки не заменяют визуальную
проверку в Safari и других браузерах.

[Отчёт об очистке и оптимизации](docs/optimization.md).
