# Панорамный первый экран

Создано 4 октября 2026 г. встроенным инструментом ImageGen (built-in tool mode).

Финальный файл: assets/hero-skyline.webp (1672×941, WebP quality 94). Это авторская AI-иллюстрация для первого экрана, не фотография объекта компании. Фактическое разрешение генерации — 1672×941; не заявляется как 4K. Исходник сохранён в Codex generated_images.

Движение реализовано только CSS transform/opacity: плавный проезд по панораме за 8 секунд в каждую сторону и проход света за 6 секунд. Отрицательная начальная задержка запускает сцену сразу в движении. На телефоне работает отдельная горизонтальная траектория с запасом изображения по краям. Анимация приостанавливается вне экрана, при скрытии вкладки, reduced motion и экономии трафика. WebGL-модель окна в следующей секции остаётся отдельной.
